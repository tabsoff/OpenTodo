# Согласованный формат разработки OpenTodo

Эти договорённости относятся к разработке пользовательской версии OpenTodo в этом репозитории.

- Основной режим доработок — локальный предпросмотр на компьютере пользователя, доступный только через localhost, с отдельной тестовой базой и вымышленными задачами.
- Для интерфейса использовать автоматическое обновление страницы при изменениях кода. При изменениях серверной части при необходимости перезапускать локальный сервер.
- Во время подбора результата показывать изменения локально. Не запускать полный GitHub CI, не открывать PR и не выкладывать каждую промежуточную правку на VPS. Локальные проверки, нужные для конкретного изменения, выполнять по мере необходимости.
- После одобрения результата пользователем оформить PR, выполнить обязательные проверки и использовать существующий процесс: тестовый сайт → проверка результата → отдельное решение о рабочем выпуске с подтверждением владельца.
- Согласие с локальным предпросмотром не является разрешением на рабочий выпуск. Рабочие данные и учётные записи не использовать для локальных экспериментов.
- Сохранять требования репозитория к спецификациям и проверкам перед выпуском. Локальный предпросмотр ускоряет итерации, а не заменяет эти проверки.

Формат согласован 23 октября 2026 года. Это фиксация договорённости; локальное окружение ещё нужно настроить и проверить перед первым использованием.
